# Notice on prior work

AbDraw implements **AbML**, an antibody markup notation published in:

> Sweet-Jones J, Ahmad M, Martin ACR. *Antibody markup language (AbML) — a notation
> language for antibody-based drug formats and software for creating and rendering
> AbML (abYdraw).* mAbs 14:1 (2022). doi:[10.1080/19420862.2022.2101183](https://doi.org/10.1080/19420862.2022.2101183)

The reference implementation of that notation, [abYdraw](https://github.com/JamesSweetJones/abYdraw),
is a Python/Tkinter application licensed GPL-3.0.

**This project shares no code with abYdraw.** The parser, layout engine, renderer and
user interface here were written from the published description of the notation. The
format library in `formats.json` is generated by `tools/build_formats.py`, which assembles
every entry from the molecular architecture of the format using scaffold builders defined
in that file; it is not a transcription of abYdraw's format table. Domain identifiers are
allocated sequentially from left to right, so for simple architectures — a plain IgG, for
instance — the resulting string necessarily coincides with any other correct AbML encoding
of the same molecule. That convergence is a property of the notation, not a copied artefact.

AbDraw is therefore released under the MIT license. If you use it in published work,
please cite the AbML paper above for the notation.
