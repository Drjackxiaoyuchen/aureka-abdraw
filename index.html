Antibody format schematics

Describe an antibody format in one line. Get a publication-ready figure.

AbDraw reads AbML — a compact text notation for antibody architecture — and draws the molecule as a domain schematic you can drop straight into a paper or a deck. 43 formats ship in the library, from a bare Fv to trispecific knob-into-hole constructs. Everything exports as vector SVG.

Why

Built for the formats that are hard to draw

Drawing an IgG is easy. Drawing a CrossMab so a reader can see which domains crossed is not — and that is exactly the figure a bispecific paper needs.

Colour follows the domain

When VH/VL or CH1/CL swap chains, the colour travels with the domain rather than the chain. A CrossMab panel reads correctly without a caption.

Text in, figure out

One line of AbML is a complete, diffable, version-controllable description of a construct. Paste it in a protocol; regenerate the figure any time.

Real vector output

SVG with live text and shapes, not a raster trace. Opens editable in Illustrator, Inkscape, Affinity and PowerPoint.

Panel figures

Stack several formats into a lettered A/B/C grid and export the whole comparison as one SVG.

Notation

AbML in a minute

A molecule is a list of chains separated by |. Each chain is a list of domains separated by -, written N-terminus to C-terminus. That alone draws a picture:

VH.a-CH1-H-CH2-CH3 | VL.a-CL

Add identifiers in parentheses to say which domains pair, a number in braces for the disulfides between them, and modification symbols for engineered interfaces. A knob-into-hole heavy chain:

VH.a(1:6)-CH1(2:7){1}-H(3:10){2}-CH2(4:11)-CH3>(5:12)
.a – .hspecificity — decides the colour of the arm
(3:10)this domain is number 3 and pairs with number 10
{2}two disulfides across that pairing
> @knob and hole
+ _charge pair
^ ! *conjugation site, aglycosyl CH2, general modification
[ANTI:CD3]comments — also MOD, TYPE, LENGTH, CLASS, NOTE

The tool carries the same reference under its Syntax tab, and the full grammar is in docs/abml.md.

Use it

Three ways to run it

In the browser

Nothing to install. Open the tool and start typing; every format is deep-linkable, e.g. app/#crossmab-ch1-cl.

One file, offline

Download app/index.html and open it locally. No build step, no network, no dependencies.

As data

formats.json carries every format as a name, category, description and AbML string, for scripting your own pipelines.
